# 🔐 Kill Switch AI

> Autonomous Wallet Protection using AI + Blockchain

## 📌 Overview

Kill Switch AI is a blockchain security platform that protects cryptocurrency wallets using AI-powered policy validation.

Before every transaction, an AI security engine analyzes the transfer and verifies:

- Daily spending limit
- Allowed wallet list
- Wallet freeze status
- Suspicious behavior

If any policy is violated, the transaction is blocked and an emergency kill switch can automatically freeze the wallet.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Aaryan2426/Kill-Switch-AI.git
```

Install frontend

```bash
cd frontend
npm install
```

Install backend

```bash
cd backend
npm install
```

Run backend

```bash
npm run dev
```

Run frontend

```bash
npm run dev
```

## 🔐 AI Security Policies

The AI engine validates:

- Daily spending limit
- Allowed receiver wallets
- Wallet freeze status
- Emergency security rules

If any rule fails:

- Transaction is blocked
- Alert generated
- Wallet can be frozen automatically
